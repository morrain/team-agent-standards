# 自研 Skill 深入设计与调试参考

本文档作为 `template-skill` 的补充参考文档，演示如何通过相对链接将大型手册渐进式加载（Progressive Disclosure）到 Agent 上下文中。

---

## 1. 为什么采用渐进式加载？
如果把上千行的文档直接全部写在 `SKILL.md` 中，Agent 只要命中该技能就会一次性消耗大量上下文 Token。通过将详细协议、配置示例和长文本分离在 `references/` 目录下，Agent 只有在执行到对应步骤时才会主动通过 `read_file` 阅读该文档，从而节约 80% 以上的上下文 Token。

---

## 2. 编写高质量 Agent 指令的原则
- **指令客观明确**：避免模糊形容词，如“尽量写好测试”，改为“测试用例需覆盖正常输入、空值输入及异常报错分支”。
- **提供反面示例 (Negative Constraints)**：明确指出 Agent 容易犯错的点，例如“严禁使用 any，遇到第三方库无类型时使用 unknown 并进行类型收窄”。
- **给出工具调用的具体命令**：指定推荐的 CLI 指令与参数。
